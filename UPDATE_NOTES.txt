VINI CAR RENTAL — UPDATE NOTES

This package carries forward the previous admin delete and premium typography changes, and adds:
- Homepage shows the complete available vehicle catalogue, not only featured vehicles.
- Every car card displays all features saved for that car.
- Homepage hero slideshow is generated from actual catalogue vehicle image_url values (up to six); no unrelated stock hero images are used.
- Admin add/edit vehicle form supports SUV, Hatchback, Sedan, Sports, Van, MUV / MPV, Luxury, Convertible, Coupe, Electric and Pickup after running the category migration.
- Admin can create a custom vehicle type from the add-vehicle form.

DEPLOYMENT
1. Back up current site files.
2. Replace app.js, styles.css, index.html and DEPLOYMENT.md.
3. Keep the existing supabase-config.js and brand image assets; the package includes the current config for reference.
4. Run supabase/vehicle-category-options.sql once in Supabase SQL Editor.
5. Keep the previously supplied supabase/admin-delete-vehicles.sql migration applied. If not yet applied, run it once too.
6. Upload the included supabase SQL files only as deployment references; SQL migrations must be run in the Supabase SQL Editor.

Existing booking flow and Supabase client configuration are preserved.
